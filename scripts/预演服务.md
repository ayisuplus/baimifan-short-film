# 本地声音预演服务

当前入口：http://127.0.0.1:8965/镜头设计/带图分镜.html#previs

音乐进度拖动需要 HTTP 字节分段响应。使用项目自带服务；普通 `python -m http.server` 在本机不支持 Range，会导致音频跳转失败。

在项目根目录打开 PowerShell，运行：

```powershell
python scripts/serve_previs.py --root . --port 8965
```

服务仅监听本机。终端按 Ctrl+C 停止；端口已占用时先确认已有服务，避免重复启动。当前工作机的 Python 完整路径是 `E:\Python\python.exe`。

更新页面源代码后，重新生成并刷新浏览器：

```powershell
python scripts/build_storyboard.py --root .
```

快捷选镜按场景分组，当前镜号与试听曲名固定显示；快捷选曲只列本画面候选。音乐和画面独立控制，切镜不停乐，每首曲的试听进度在本次页面会话内保留。刷新页面会清空试听状态；试听选择不等于正式采用。

每首候选下的“选定本镜 BGM”用于标记，再点可取消，改选另一首会替换本镜标记。标记保存在当前浏览器的本机存储中，刷新保留；浏览器清理站点数据会移除标记，不会自动写入项目配乐编排。试听不会更改标记。
