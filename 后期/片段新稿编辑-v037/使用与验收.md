# 118 段剧本、提示词新稿编辑 v037

工作入口仍为 [白米饭 · 全片画面 v035](http://127.0.0.1:8978/editor/restored-ad3867fc-177c-4371-bb51-7ed75d686e30)。v037 是本轮功能和核验记录，不是新的剪辑版。

## 使用

1. 点时间线片段，左侧“本镜文字 → 本段新稿”。
2. 选“编辑剧本”或“编辑提示词”，直接修改文字。多来源片段保留各自段落，例如003有三段剧本，041有四组提示词。
3. 点“另存新稿”：新建磁盘版本，不覆盖历史。切镜和刷新会保留本窗口未保存输入，但长期保存仍应另存，并定期点“工程备份”。
4. “新稿历史与版本核对”可载入旧稿或来源底稿。载入只改变编辑框，可以撤销；再保存才产生下一版。
5. “历史来源”继续查看原始剧本出处、实际执行提示词与来源说明。右侧参考图不变。完整场景剧本仍有独立入口，本段改稿不会自动改整场。

新提示词标明“尚未执行”，保存不触发生成，也不替换视频。105片段只有本地静图推进记录，其新提示词框为空；本地命令保留在历史来源中，不冒充生视频提示词。

若另一窗口已经保存同段，旧版本保存会被拒绝，当前输入保留。点“检查最新稿”，展开磁盘最新稿核对，确认后以当前输入另存下一版。不要靠反复点击覆盖冲突。
