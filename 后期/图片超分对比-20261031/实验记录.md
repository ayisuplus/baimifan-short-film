## 观察与选择

| 方法 | 本次可见变化 | 用法建议 |
|---|---|---|
| 原图 + Lanczos | 保留源信息与原画，但放大后边缘较软 | 对照基线；不要求额外细节时可直接用原图 |
| RTX ULTRA | 轻度收紧边缘，笔触、明暗块和龙纹形状整体最接近原图；改善较克制，局部仍有细碎边缘 | 保留原资产感觉、快速放大时先试 |
| Real-ESRGAN x4plus | 眼睛、文字、衣缘更清楚，线条平顺；手部、脸颊及衣料的小笔触会被平滑，形成更干净的色块 | 动漫画面希望更利落时的候选；仍须看局部 |
| SeedVR2 7B Q8 | 精细化明显，但近景泪珠、睫毛、发丝与衣纹被重新解释；宫殿龙纹及金属装饰产生明显新纹样 | 单独审查的增强选项，不直接批量替换人物或标志纹样资产 |

最有辨识力的证据：

- [近景眼睛](comparisons/closeup_face.png)：SeedVR2 改动了泪珠形状并强化细线；Real-ESRGAN 更平顺。
- [手部](comparisons/closeup_hands.png)与[发丝](comparisons/closeup_hair.png)：比较轮廓与原始涂绘块面，避免把新增细线都当作恢复。
- [全身脸部](comparisons/fullbody_face.png)、[衣纹](comparisons/fullbody_clothes.png)、[文字](comparisons/fullbody_text.png)：人物身份整体保持，Real-ESRGAN 平滑较强；SeedVR2 对雪花/褶皱有额外解释。
- [宫殿龙纹](comparisons/palace_ornament.png)：SeedVR2 将原龙纹补成另一套精细纹路，这是不宜默认采用的直接证据；[王座](comparisons/palace_throne.png)与[地面](comparisons/palace_floor.png)也可见重构和平滑的差别。

## 输入与比较口径

全身样本是包含全身人物、帽子、披风、靴子及标注的整张服装母版，没有另造一张全身图。输入转换为 RGB PNG；原始文件 SHA-256 已复核未改，路径与哈希见 [samples.json](samples.json)。输入本身已有插画细节，并非人为压缩或先缩成低清。

“4K”在此指长边 3840，保持原比例，不裁切为统一 UHD 画框。基线为原图 Lanczos 插值到同尺寸，并非真实 4K 标准答案。各模型输出后都经过 ImageScale/Lanczos 对齐目标尺寸：RTX 的原生高度按 8 对齐为 2160 / 1648；SeedVR2 近景、宫殿原生输出 3840×2160，最后作微小尺寸对齐。局部板为输出相同坐标的原生像素裁切；网页缩略图不能替代 100% 查看。

## 执行参数与耗时

本机 RTX 5090，约 32 GB 显存；现有 ComfyUI `G:\comfyui\ComfyUI\ComfyUI`，CUDA PyTorch 2.10.0+cu130，端口 8188。节点发现、上传、在线预检、提交、状态和下载 URL 均使用已安装的 comfy CLI 1.22.0。

- **常规超分**：`RealESRGAN_x4plus.safetensors`，模型原生 4 倍，然后 Lanczos 到目标尺寸；无面部修复。
- **SeedVR2**：现有节点 v2.5.24；`seedvr2_ema_7b-Q8_K_M.gguf`、`ema_vae_fp16.safetensors`；seed 20261031，batch 1，短边 2162 / 1646，长边上限 3840；LAB 色彩校正；输入/潜空间噪声 0；SDPA；32/36 blocks swap 到 CPU；VAE 编码、解码均 1024 tile / 128 overlap；不预缩输入，不做提示词重绘。
- **RTX**：现有 `comfyui_nvidia_rtx_nodes` 的 `RTXVideoSuperResolution`，质量 ULTRA，目标长边 3840；本地版本只有 LOW / MEDIUM / HIGH / ULTRA 四档。未启用 HDR，未安装或更新节点、模型、依赖。上游较新版本的 HIGHBITRATE 模式不在本次测试内。

9 份工作流均在本机在线预检通过，`data.valid=true`，0 错误、0 警告；9 份终态均 completed，输出尺寸与 SHA-256 见 [results.json](results.json)。详细回执在 `receipts/`，API 工作流在 `workflows/`。原始结果保留于 ComfyUI 的 `output/Baimifan/Upscale_20261031/`，本目录 `outputs/` 是用于比较的副本。

## 复看与后续接入

`prepare.py` 只重建、预检工作流，不提交 GPU 任务；`collect.py` 读取已有 prompt ID 终态并复制原生结果；`make_comparisons.py` 重建局部板。媒体沿用项目既有规则留本地、不纳入 Git；文本、参数和回执入库。

建议 OpenCut 将放大作为可选操作，提供原图 / RTX 快速放大 / Real-ESRGAN 线条增强 / SeedVR2 细节增强及并排审阅；这是本次建议，尚未修改产品或默认配置。三组静态图不能证明图生视频会更好，仍应按实际 H3 工作流输入尺寸准备，并另做视频 A/B 才能判断。

技术来源：[NVIDIA RTX Video SDK](https://developer.nvidia.com/rtx-video-sdk)明确支持创作应用离线处理；[Comfy 官方 RTX/VFX 节点](https://github.com/Comfy-Org/ComfyUI_Nvidia_VFX_Nodes)支持 IMAGE 输入、IMAGE 输出和 SaveImage。驱动中的播放器增强开关与可保存图片的工作流是不同入口。
