## Rust 创作工程与时间线联动

场次、动作/对白、提示词、校验、版本保存与历史恢复已迁入 OpenCut `rust/crates/creative`。编辑表单是 OpenCut 原生界面，已经移除 iframe 和对独立 Python 保存服务的依赖。时间线匹配规则编译为 WASM，缓存片段关系，播放时只传当前位置。

- 点下方片段：上方创作内容和当前画面定位到对应镜头。
- 点剧本镜号或“定位片段”：选中时间线实际片段并定位画面。同镜切分或重复时优先保留当前选中的那一段。
- “跟随播放位置”：播放与拖动游标时跟随当前镜头。未保存、正在保存或输入框获焦时暂缓自动跟随，避免打断输入。
- 保存与版本冲突在 Rust 中处理；页面能查看并恢复历史，恢复产生新版本。草稿仍按本窗口场次/批次暂存。

新工作稿唯一存于 `.opencut-creative/versions/`，最大完整版本号为当前正文。旧 `导演台/.creative-workbench/project.json` 保持原样并写入只读归属标记，旧服务已停止；完整旧稿及历史在新目录 `legacy/` 另有备份。历史备份和锁文件不进入 Git，完整迁移备份请包含整个目录。

当前正式稿为原生版本 3，内容与迁移初稿一致：版本 2 仅为动作/对白保存验收记录，已通过追加版本 3 恢复。原剧本、冻结提示词、录音和视频未改。时间线切分验收已撤销，仍为原来的三个片段、336帧。

浏览器剪辑工程沿用 OpenCut IndexedDB/OPFS；创作资料由同一 OpenCut 应用的 Rust 模块保存于作品目录。尚未宣称整个 OpenCut 都完成 Rust 化，也未接入上游重写版 SDK。

## 重建与启动

```powershell
python 'E:\projects\内容创作\故事短片\白米饭\scripts\build_opencut_director_prototype.py'
& 'E:\projects\媒体后期\OpenCut-classic\Start-Director-Prototype.ps1' -PackageRoot 'E:\projects\内容创作\故事短片\白米饭\后期\OpenCut导演台原型-v001\package'
```

原启动命令构建 Rust native/WASM，核验并停掉该作品旧服务，执行幂等迁移，再启动或复用 OpenCut。旧工作区有归属标记后，媒体包重建只读旧适配资料，不覆盖 Rust 工作稿。构建仅复制媒体及 CPU 提取试听声，不加载生成模型。初次环境需 wasm32-unknown-unknown 和 wasm-bindgen-cli 0.2.116，详见 OpenCut 的 docs/director-prototype.md。

实现仍位于本机 OpenCut Classic；未宣称已接入上游重写版。技术验收与作者创作终验分开记录。
