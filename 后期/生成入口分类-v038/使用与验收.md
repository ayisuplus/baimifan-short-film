# 生成入口分类 v038

当前仍使用 [OpenCut 白米饭全片 v035](http://127.0.0.1:8978/editor/restored-ad3867fc-177c-4371-bb51-7ed75d686e30)，本轮只是生成参数入口更新。

右侧选「生成」，分为 ComfyUI 和 RunningHub：

- ComfyUI：已有 H3 白米饭图生视频、Qwen 白米饭关键帧、RTX / Real-ESRGAN / SeedVR2 可准备参数；另外收录 7 个原画布，其中 3 个声音工作流折叠保留。原画布需先导出并核对 API 格式，暂不能准备。
- RunningHub：仅 MiniMax H3、Seedance 2.5、RH 视频超分。后者使用完整源视频，选择 4K 等目标分辨率，不使用参考图或提示词，也不按时间线裁切。Seedance 2.5 来自本机已有 Skill 目录，当前下载的公开清单缺失，入口明确标为待在线核验；没有换成别的模型。
- 生视频读取左侧已保存提示词，多个来源组可以选择；参考图来自本段已有素材。未保存文字会提示先保存。按钮只有「准备参数（不生成）」，不会上传或提交。
- ComfyUI 下「已有超分任务与候选」保留旧结果查看和候选导入；手动查询历史回执可能访问本地 ComfyUI，不会重新提交任务。

H3 白米饭模板仍是原来的 2.5 秒 / 24fps / 1344×768，含原生音频输出；本轮不改其流程。云端账户权限和实际生成未验收。下一步执行接口仍需核对最新模型参数、视频时长等约束。

## 恢复

现有完整工程继续用 [v037 完整备份](../片段新稿编辑-v037/工程入口.json)。本次额外保存 `配置快照/`，包含全局生成目录、工作流快照、模型参数和验收记录，不包含凭据。恢复入口时，把 `配置快照` 内容复制到 OpenCut 仓库 `.local/generation`，然后在界面点「刷新目录与保存稿」。旧目录应先另存备份。

`公开模型清单.json` 是当时核对的官方公开资料快照，不代表云端账号权限或未来可用性。代码与影片配置分别提交，提交信息见 `工程入口.json`。
