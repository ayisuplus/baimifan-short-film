# 两个陷阱

## 1. `-v053` 重号，两者是不同的东西

| 目录 | 文件 | 是什么 |
|---|---|---|
| `余波与锁痕-v053` | 2 | 预演编排 + 作者确认选曲 —— **逐镜选曲记录** |
| `最终审查-v053` | 38 | 全片结构与音频核验、前后半视觉审查 —— **全片审查记录** |

版本号在这里是**镜号／编号**，不是全局版本序列。同号不同事，按名称判断，别按版本号排新旧。

## 2. 版本号不代表时间顺序

- 大部分目录的文件修改时间同为 `2026-10-26 18:18`，那是项目迁移落盘的时间戳，**不是创作时间**。
- `-v045` 到 `-v058` 这一段是逐镜作业编号，与 `-v033`（工程基线）、`-v035`（剪辑工程）**不同源**。
- 判断新旧请看目录内的 `修订说明.md`、`工程入口.json`、`作者已选记录.json`，不要只看目录名版本号。

2. **9 个目录未被 git 跟踪**：`全片画风统一-v007`、`日语配音接线-v019`／`v020`、`日语配音修正-v002` ～ `v005`、两个空目录。Git 记录不表示这些内容已被备份。
