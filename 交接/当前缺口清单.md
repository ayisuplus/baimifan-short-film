# 四、执行时的两个硬约束

## 1. 生成闸门
`当前制作状态.json` 当前 `status=archived`（定档）、`auto_resume=false`。
`run.py` / `production.py` 的 `submit()` 会**直接断言失败**，除非把状态显式改成 `active`。这是设计如此，不是故障。
另外：本清单所依赖的 v034 候选素材已作废（见[定档说明](定档说明.md)第四节），清单保留作溯源。

## 2. GPU 被占
RTX 5090 32GB 中已用 19GB（99% 利用率），**Blender 两个进程**（约 12GB）占用，很可能是《未来女孩林知夏》的场景编辑。
ComfyUI 自身约 3.6GB，队列 0/0。

## 3. 运行中不可做
- `build_master.py` 在缺镜时**拒绝生成最终清单**——不要跳过 pending 宣称完整。
- `resolve_conform.py` 已备好但**尚未执行**，需完整动态验收通过后才运行。
- `edits/install-manifest.json` 的已剪素材**从 0 帧开始**，不要再套一遍原片裁切点。
